JavaScript Practice & Timer App:
This project is a small collection of JavaScript tasks along with a simple one-hour countdown timer built using HTML, CSS, and JavaScript.

Features:
~ Countdown timer (1 hour) with Start, Pause, and Reset
~ Find the second largest number in an array
~ Get unique elements from two arrays
~ Student score analysis (top student by average)

Tech Used:
~ HTML
~ CSS
~ JavaScript

Files:
index.html – Timer UI and functionality
javascript.js – JavaScript practice problems

How to Run
Download or clone the repository
Open index.html in your browser
Use the timer or check the console for outputs
